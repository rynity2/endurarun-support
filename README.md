# EnduraRun support

Support page and privacy policy for EnduraRun, a running metronome and coach for iPhone and Apple Watch.

- Support: https://rynity2.github.io/endurarun-support/
- Privacy policy: https://rynity2.github.io/endurarun-support/privacy/

Need help with the app? [Open a support request](https://github.com/rynity2/endurarun-support/issues/new).
Requests are public, so please leave out personal or health details.
